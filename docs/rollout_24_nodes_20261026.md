## 交接顺序与防重复

先完成目录分片原有顺序交接，再交接普通文件，避免违反原目录协调器对文件进程身份不变的约束。

每个分片均按以下顺序执行：验证目标主机/boot/挂载 → 在远端预置等待进程 → 使用 pidfd 对原进程发送优雅排空信号 → 等待实际退出 → 校验完整已提交清单前缀与回执 → 发布闭合证明 → 远端再次核对 → 仅处理后缀 → 检查累计计数连续 → 交接下一分片。

交接期间其余分片继续复制。单个分片存在排空、回执读取和核验空窗，不承诺零空窗。远端启动结果不明确时停止协调并等待检查，不自动重发启动、不重复派发。
