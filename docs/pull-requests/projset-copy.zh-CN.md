# 新增 projset 多节点复制与 SwanLab 总览，整理分析归档

`projset → project` 迁移需要独立的复制、进度和逐路径异常记录；现有分析脚本、历史报告与大型清单也缺少统一入口。本次补齐这些工具，并将源码、测试、静态归档和运行证据分别整理。

## 变更

- 新增有界的多节点扫描与复制，保持相对路径，复用 SHA-256、目标读回校验和无覆盖发布；不同内容的已有目标保留并记录冲突。
- 新增独立 SwanLab 上报器，每120秒合并上报，容量用TB、速率用TB/s；总览集中显示已确认容量、TB/h完成速度、在线节点及异常。
- 增加逐节点进程/cgroup/OOM诊断，以及每120秒增量更新的成功复用、冲突、源变化和错误路径清单，记录容量、原因、两侧属性和回执位置。
- 将分析工具、测试和历史PR说明移入对应目录；集中归档空间分布报告及JSON/CSV证据，更新README、目录索引和图表说明。
- 将约287MB的大型静态清单无损压缩至约29MB，记录压缩前后SHA-256；分析器直接读取压缩CSV。
- 排除实时 `runs/`、日志、缓存和个人编辑器配置；修复新增测试对源码布局的依赖，兼容任意位置的平铺运行包。

## 验证

- 409个打包Python文件语法检查通过，运行包文件名无冲突。
- 18项新增功能测试在源码目录和平铺运行包中均通过，另有9项仓库工具测试通过，共27项不同测试。
- 三份gzip归档均解压读回验证原始SHA-256；新增文档相对链接及 `git diff --check` 通过。

## 运行边界

已有任务继续使用原路径下的冻结代码。总范围尚未确定时，总览不生成完成百分比或ETA；报告刷新不触发异常重试或目标覆盖。目录元数据及硬链接拓扑仍需收尾验收，在线源复制不构成时间点快照。
